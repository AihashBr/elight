# Elight vision

Elight is a game engine built around local AI. Games made with it can run language and other models on the player's device, with no server and no cloud cost.

## Principles

- **Local first:** AI runs on the player's machine. Cloud is optional, never required.
- **Cross-platform:** desktop, mobile and the browser (see decision 0001).
- **AI is transparent:** the editor and the game always show what the model is doing and what it costs (time, memory).
- **Never block the frame:** inference is asynchronous and budgeted.
